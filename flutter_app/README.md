# Vanakamsmps Flutter (overall equivalent)

This is a Flutter starter app that mirrors the **overall structure** of the original web platform:

- Home/dashboard
- Shop
- Forum
- Support tickets
- Profile

## Run

```bash
cd flutter_app
flutter pub get
flutter run
```

## Notes

- The project uses mock data and UI placeholders so you can wire your real backend APIs.
- Theme and layout are inspired by the same dark, community-first style as the website.
